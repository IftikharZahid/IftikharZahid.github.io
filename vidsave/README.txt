Google Search Console Steps:
----------------------------
1. Go to Google Search Console (https://search.google.com/search-console).
2. Add URL prefix: https://iftikharzahid.me/vidsave/
3. Verification: Replace "GSC_VERIFICATION_TOKEN_REPLACE_ME" in index.html with your actual HTML meta tag token (or upload the HTML file if using file verification).
4. Sitemaps: Submit https://iftikharzahid.me/vidsave/sitemap.xml in the Sitemaps tab.
